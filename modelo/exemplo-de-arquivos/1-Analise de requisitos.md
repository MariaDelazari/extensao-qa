# Análise de Requisitos

Escreva um bloco para cada regra que deu para observar. Troque o texto abaixo pelo que o sistema faz. Não invente requisito para completar a lista.

### RF01 - Nome curto da regra

**Descrição:** Em uma ou duas frases, o que o sistema deve permitir ou impedir.

**Funcionalidades esperadas:**

- Ação que a pessoa faz na tela.
- O que o sistema confere.
- Para onde a pessoa vai, ou qual mensagem aparece.

**Resultado esperado:** A frase que define se essa regra foi cumprida.

---

### RF02 - Próxima regra

**Descrição:** Mesma estrutura do RF01.

**Funcionalidades esperadas:**

- Primeiro ponto observável.
- Segundo ponto observável.

**Resultado esperado:** O que precisa aparecer na tela para a regra valer.
